# Moodle Customizations

This repo contains a record of custom HTML and SCSS snippets we use for Moodle customization.

## HTML

The HTML snippets are copy-pasted into the inputs in the _Appearance_ > _Appearance_ > _Additional HTML_ page of the _Site administration_.  The _custom.js_ file contains the JS in the _footer.html_ file as pure JS, for development convenience.

## SCSS

The SCSS files are uploaded as files in the _Appearance_ > _Boost Union_ > _SCSS snippets_ page.  The existing files can be deleted and new versions uploaded on the _Settings_ tab, and individual snippets can be enabled or disabled with the "eye" icon on the _Overview_ tab.
